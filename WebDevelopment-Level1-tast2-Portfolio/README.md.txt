# Personal Portfolio Website

## OIBSIP - Web Development & Designing
### Level 1 - Task 2: Personal Portfolio

## About The Project

This project is a personal portfolio website created as part of my
Oasis Infobyte Web Development & Designing Internship.

The portfolio showcases my profile, skills, projects, and contact
information in a clean, modern, and responsive design.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- JavaScript (Optional)

## Features

- Responsive navigation bar
- Hero/Profile section
- About Me section
- Skills section
- Projects section
- Contact section
- Smooth scrolling navigation
- Responsive design for desktop and mobile
- Consistent colour scheme and typography

## Sections

### 1. Hero Section

Includes:
- My name
- My role
- Professional profile image
- Short introduction
- View Projects button
- Contact Me button

### 2. About Me

A short introduction about my background,
interests, and career goal in web development.

### 3. Skills

The portfolio displays my technical skills, including:

- HTML
- CSS
- JavaScript
- C
- C++
- Java
- Git & GitHub

### 4. Projects

The projects section showcases my work with:

- Project title
- Project description
- Project link

### 5. Contact

The contact section contains:

- Name
- Email
- Message
- Social links

## Responsive Design

The website is designed to work properly on:

- Desktop
- Tablet
- Mobile

CSS media queries are used to adjust the layout for smaller
screen sizes.
