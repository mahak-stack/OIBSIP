# Fashion Brand Landing Page

## About the Project

This project is a responsive fashion brand landing page created as part of the Oasis Infobyte Web Development & Designing internship.

The landing page is designed to provide a clean and attractive interface for a fashion brand. It includes a navigation bar, hero section, product/content sections and a footer.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive design
- Navigation bar
- Attractive hero section
- Fashion/product sections
- Image-based content
- Responsive layout for different screen sizes
- Clean and simple user interface

## Project Structure

- index.html - Main HTML file
- style.css - Styling and responsive design
- images/ - Project images
- Screenshots/ - Project screenshots

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in any web browser.
