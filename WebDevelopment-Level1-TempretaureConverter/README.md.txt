# 🌡️ Temperature Converter Website

## 📌 Project Overview

The Temperature Converter is a responsive and interactive web application developed as part of my Web Development & Designing Internship at Oasis Infobyte.

This website allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with a simple and user-friendly interface.

## ✨ Features

- **Temperature Conversion:** Converts temperatures between Celsius, Fahrenheit, and Kelvin.
- **Modern UI:** Clean design with an animated gradient background.
- **Smooth Animations:** Interactive hover effects and animated result display.
- **Temperature Indicator:** Displays dynamic emojis and messages based on the converted temperature.
- **Reset Button:** Clears the entered temperature and resets the result.
- **Input Validation:** Displays error messages for empty or invalid input.
- **Absolute Zero Validation:** Prevents temperatures below absolute zero.
- **Responsive Design:** Designed to work on desktop and mobile screens.
- **Keyboard Support:** Press Enter to convert the temperature.

## 🛠️ Technologies Used

- HTML5 — Structure of the website.
- CSS3 — Styling, responsive layout, and animations.
- JavaScript — Temperature conversion, DOM manipulation, event handling, and validation.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Enter a temperature in the input field.
5. Select Celsius, Fahrenheit, or Kelvin.
6. Click the **Convert Temperature** button to see the results.
7. Use the **Reset** button to clear the input and result.

## 🧮 Conversion Formulas

- **Celsius to Fahrenheit:** (°C × 9/5) + 32
- **Fahrenheit to Celsius:** (°F − 32) × 5/9
- **Celsius to Kelvin:** °C + 273.15
- **Kelvin to Celsius:** K − 273.15

The application converts the selected input into Celsius internally and calculates the corresponding Fahrenheit and Kelvin values.
